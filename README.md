# Programs

## Ludo

Open `index.html` in a browser to play Ludo locally. Choose 2, 3, or 4 players; players take turns on the same device. The responsive, colorful board includes animated dice, highlighted legal moves, and home-progress indicators.

The game includes rolling a six to leave the yard, extra turns for sixes/captures/finishes, safe squares, captures, blockades, exact rolls to finish, and the three-sixes turn penalty.

## Prime number checker

Run `python prime_checker.py` and enter an integer when prompted.
